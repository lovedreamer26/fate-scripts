# Fate Scripts

Редактор и локальная библиотека JavaScript-макросов для Foundry VTT v14. Интерфейс Arcane Studio входит в экосистему Fate & Roll.

[Установка и подключение Bridge](docs/MVP_QUICKSTART.md)

Для проверки исходников выполните npm ci, npm test и npm run build. Для сборки Windows x64 выполните npm run tauri -- build --bundles nsis.
