# Fate Scripts

Редактор и локальная библиотека JavaScript-макросов для Foundry VTT v14. Интерфейс Arcane Studio входит в экосистему Fate & Roll.

[Установка и подключение Bridge](docs/MVP_QUICKSTART.md)

Для проверки исходников выполните npm ci, npm test и npm run build. Для сборки Windows x64 выполните npm run tauri -- build --bundles nsis.

## Каталог макросов GitHub

В каталоге нажмите «Найти новые макросы», отметьте направления и при необходимости добавьте свой запрос. Перед запуском можно просмотреть итоговый список. Поиск просматривает до двух страниц GitHub на запрос и проверяет публичные источники через существующий индексатор. Направление «Все макросы D&D 5e» также проверяет четыре стартовые коллекции.

«Остановить поиск» сохраняет очередь. После перезапуска или ограничения GitHub откройте диалог и нажмите «Продолжить поиск», когда кнопка станет доступна. Счётчик показывает файлы-кандидаты. Откройте карточку для проверки исходника и метаданных перед импортом. Результаты поиска сами по себе не подтверждают совместимость с Foundry v14.

В «Каталог GitHub» откройте «Источники GitHub», укажите публичный репозиторий и нажмите «Обновить каталог». Укажите ID репозитория в формате владелец/репозиторий. Успешная проверка обновляет дату источника. При сетевой ошибке или лимите GitHub сохранённые карточки остаются доступными.

«Подробнее» открывает метаданные, а вкладка «Исходный код» показывает текст в Monaco. Категория и система, полученные из пути или анализа, помечаются. Раздел совместимости показывает заявления автора; проверка в Foundry v14 требует отдельного испытания. «В библиотеку» открывает независимую копию для сохранения.

Встроенный словарь переводит распознанные названия. Для полных переводов скопируйте шаблон из карточки, переведите значения в удобном переводчике и загрузите JSON через «Источники GitHub». Ключи из шаблона оставьте как есть. Переводы хранятся локально и применяются к тем же исходным метаданным. После их изменения карточка показывает оригинал до загрузки нового перевода. Исходный JavaScript, имена API и лицензионные уведомления в шаблон перевода не входят.
