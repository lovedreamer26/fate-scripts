# Fate Scripts 1.0.0. Краткая инструкция

## Установка

1. На Windows x64 запустите Setup.exe. Для обновления закройте Fate Scripts и установите новую версию поверх прежней. Библиотека хранится отдельно от программы в %LOCALAPPDATA%\com.fateandroll.scripts.
2. Закройте Foundry. Распакуйте Fate-Scripts-Bridge.zip в папку Data/modules вашего каталога пользовательских данных Foundry. Должен получиться путь Data/modules/fate-scripts-bridge/module.json.
3. Запустите Foundry VTT v14, откройте нужный мир как GM и включите Fate Scripts Bridge в управлении модулями.

## Работа

1. Нажмите «Новый скрипт» или откройте «Каталог GitHub». Добавьте публичный репозиторий, откройте нужный файл и нажмите «Импортировать копию».
2. Отредактируйте JavaScript и нажмите «Сохранить». Для организации библиотеки используйте папки и поиск в левой панели.
3. В Foundry VTT v14 войдите мастером. В Fate Scripts откройте «Foundry — сессия GM», введите локальный адрес и ID мира, затем нажмите «Начать сопряжение».
4. В настройках Foundry откройте «Fate Scripts — сопряжение GM», введите одноразовый код и подтвердите. Дождитесь статуса «Подключён» в Fate Scripts.
5. В редакторе нажмите «Отправить в Foundry» и проверьте сравнение в диалоге GM. Первая подтверждённая отправка создаёт макрос, следующие обновляют тот же макрос. При конфликте с изменениями в Foundry сначала проверьте его текущий код.
6. Для запуска сохранённого скрипта добавьте его на панель запуска и нажмите кнопку. Результат появится на кнопке и в журнале Bridge. При статусе «Исход неизвестен» сначала проверьте Foundry.
